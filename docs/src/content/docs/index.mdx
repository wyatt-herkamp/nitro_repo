<Aside type="caution" title="2.0 is in beta">
  The 2.0 rewrite moved the backend from Actix to Axum and from Sea-ORM to SQLx,
  and moved repository and storage configuration into Postgres. It is usable,
  and breaking changes are still on the table. These docs describe 2.0; anything
  written for 1.x no longer applies.
</Aside>

<CardGrid>
  <Card title="Maven" icon="seti:java">
    Hosted and proxy repositories, generated `maven-metadata.xml` including
    timestamped snapshots, checksum verification on upload and generation on
    demand, and push rules that are actually enforced.
  </Card>
  <Card title="npm" icon="seti:npm">
    A hosted registry: scoped packages, dist-tags, publish, unpublish,
    deprecate, search, and both login flows — including the browser one that npm
    9 and later default to.
  </Card>
  <Card title="Storage you choose" icon="seti:folder">
    The local filesystem, a self-contained single-file object format, or S3 and
    anything S3-compatible. Storages are configured at runtime, not at build
    time.
  </Card>
  <Card title="Search" icon="magnifier">
    A small query language over projects and versions, exposed both as plain
    text search and as a full query syntax with globs and date comparisons.
  </Card>
</CardGrid>
